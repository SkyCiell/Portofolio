## 🎨 Design Philosophy & Aesthetics

Designed with an **editorial magazine, high-fashion, and modern architectural** direction:

- **Strict Editorial Color Palette**:
  - Canvas: `#181818` (Matte Dark Charcoal)
  - Primary: `#A97843` (Metallic Bronze)
  - Accent: `#D4A96A` (Champagne Gold)
  - Text: `#F3EFE8` (Editorial Off-White)
- **High-Impact Typography**: Cormorant Garamond (Editorial serif display) paired with Sora and Space Grotesk for crisp technical readability.
- **Architectural Navigation Rail**: Vertical side dock with chapter indexing (`01 // COVER` to `06 // INQUIRIES`) that transforms gracefully on mobile.
- **Museum Exhibition Works**: Projects presented as high-fashion monographs with asymmetric spreads, custom browser chrome frames, and technical highlight blocks.
- **Competency Catalog**: Typographic skills catalog without generic progress bars or percentages.
- **Tactile Micro-interactions**: Grain texture overlay, scroll-reveal observers, live WIB time clock, toast notifications, and dark/light mode toggle.

## 💻 Local Development

Clone this repository and open `index.html` directly in any web browser or start a local HTTP server:

```bash
# Clone repository
git clone https://github.com/SkyCiell/Portofolio.git

# Navigate into workspace
cd Portofolio

# Start local server (optional)
python -m http.server 8000
```
Open `http://localhost:8000` in your web browser.
